# Эталонный оценщик (Python)

Независимая реализация правил напора v0 — «оракул» для тестов GDScript.
Не входит в игру. Нужен только для перегенерации `tests/fixtures/`.

- `pressure_ref.py` — оценщик (мокрая сеть, протечки, Дейкстра) и полный перебор поворотов.
- `wetsearch_ref.py` — перебор только мокрых сетей (сверен с полным перебором на 27 уровнях).
- `export_fixtures.py` — пишет `examples.json` и первую половину `eval_golden.json`
  (вторая половина — сети из перебора; скрипт для неё в истории PR T-03).

    cd tools/reference && python3 export_fixtures.py ../../tests/fixtures

Если правила в GAME_DESIGN.md меняются — сначала меняем эталон, потом GDScript,
потом перегенерируем fixtures.
