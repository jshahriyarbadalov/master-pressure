## Как воспроизвести

Всё детерминировано от seed: те же команды дают те же уровни (проверено побайтно) и те же партии бота (два независимых прогона 7×9 совпали).

```
# генерация (по 200 уровней на размер)
godot --headless -s tools/gen_levels.gd -- --size 5x5 --taps 2 --count 200 --seed 10000 --out gen/5x5.jsonl
godot --headless -s tools/gen_levels.gd -- --size 6x6 --taps 2 --count 200 --seed 20000 --out gen/6x6.jsonl
godot --headless -s tools/gen_levels.gd -- --size 6x7 --taps 3 --count 200 --seed 30000 --out gen/6x7.jsonl
godot --headless -s tools/gen_levels.gd -- --size 7x8 --taps 3 --count 200 --seed 40000 --out gen/7x8.jsonl
godot --headless -s tools/gen_levels.gd -- --size 7x9 --taps 3 --count 200 --seed 50000 --out gen/7x9.jsonl
# агент (перепроверка + 3 партии бота)
godot --headless -s tools/agent_player.gd -- --in gen/5x5.jsonl,gen/6x6.jsonl,... --out results.jsonl --runs 3
# отчёт
godot --headless -s tools/report.gd -- --in results.jsonl --md docs/reports/levels_1000.md --csv docs/reports/levels_1000.csv
```

Время в облачной песочнице (2 ядра): генерация 1000 уровней ≈ 50 мин (7×9: в среднем 4,6 с на уровень), агент ≈ 45 мин.

## Выводы и ограничения

- Бот — не человек. Он не видит «смысла» уровня, а только локально улучшает напор; его касания — грубая мера сложности. Финальное слово — твоя игра на телефоне (этап 4).
- Подобранные веса — предложение, в `difficulty.gd` не внесены.
- 7 колонок — по решению из GAME_DESIGN (9 колонок не влезают при 48 dp).
